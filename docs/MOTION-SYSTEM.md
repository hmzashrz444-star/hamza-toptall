## Interaction language

- Pointer position changes the chromatic focal point and portrait depth.
- The identity mark responds with a controlled rotation and glow.
- Name lines shift independently to preserve the two-part typographic concept.
- Portrait hover accelerates the orbital system and subtly increases color depth.
- The primary control is magnetic but returns to a stable neutral position.
- The native system cursor is preserved so hover states never create duplicate rings or pointer artifacts.
- Pointer lighting is transform-driven; live coordinates are intentionally throttled for smoothness.

## Motion principles

- No shared blanket reveal is used for primary cover elements.
- Motion explains hierarchy instead of decorating every object.
- Reduced-motion preferences collapse the timeline without hiding content.
- Timing remains confident and readable during screen sharing.
- Continuous background animation is avoided so the presenter remains the focal point.
