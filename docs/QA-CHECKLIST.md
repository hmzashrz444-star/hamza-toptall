# Presentation QA Checklist

## Before the interview

- [ ] Preview at 16:9 and the exact screen-sharing resolution.
- [ ] Confirm the HBS intro, skip control and cover animation complete cleanly.
- [ ] Test Right, Down, Page Down, Enter and Space navigation.
- [ ] Test Left, Up, Page Up and Home fallback behavior.
- [ ] Verify the favicon and all local images load with the network disabled.
- [ ] Confirm reduced-motion mode exposes all content.
- [ ] Keep authoritative Figma files and public sites open in separate tabs.
- [ ] Confirm no private repository content appears in distributable files.
- [ ] Close unrelated notifications and applications before screen sharing.

## For every future slide

- [ ] Use only verified claims and real artifacts.
- [ ] Check text readability at actual presentation size.
- [ ] Give each transition a reason tied to hierarchy or narrative.
- [ ] Verify no content clips at 16:9.
- [ ] Keep keyboard navigation intact.
- [ ] Recheck total pacing against the 18–20 minute target.
